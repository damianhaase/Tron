# Tron Comic Series: Project Overview

## What This Is
A multi-season prestige drama comic book series set in the Tron universe. The goal is to craft a serialized story that works at every structural level—from individual scenes to the 5-season arc—while exploring a deep thematic question across multiple character perspectives and institutional settings.

## The Creative Philosophy
- **Respect canon, improve where needed**: Existing Tron material is rich. We keep what works, replace what doesn't, and expand what's underdeveloped.
- **Think visually first**: Every scene is written as panels, not prose. The image comes before the dialogue.
- **Structure serves story**: We use the Hierarchy of Arcs (Series → Season → Episode → Scene) to ensure every moment serves both the immediate beat and the larger argument.
- **Character over plot**: We build a character web where no single person is load-bearing to the series. Characters can transform, exit, or even die without collapsing the story.

## The Agent System
This project uses 10 specialized agents to guide the creative process. See `.claude/agents/` for detailed instructions for each:

1. **The Cataloguer** — Maps existing canon, identifies patterns, flags deviations
2. **The Interviewer** — Challenges assumptions, asks clarifying questions
3. **The World Builder** — Adds thematic depth, visual richness, metaphorical consistency
4. **The Story Architect** — Structures stories via the Hierarchy of Arcs
5. **Multi-Variant Plotter** — Brainstorms alternative directions, explores edge cases
6. **Script Format & Pacing Master** — Enforces comic formatting, controls pacing
7. **Dialogue Coach** — Suggests character-specific, natural dialogue
8. **The Humanizer** — Strips robotic phrasing, ensures authenticity
9. **Character Bible Keeper** — Maintains character consistency across seasons
10. **Visual Prompt Generator** — Converts script descriptions to image generation prompts

### How to Invoke Agents
In conversation, reference agents by name or role:
- "Ask the **Cataloguer** about [topic]"
- "The **World Builder** should add..."
- "Run this through the **Story Architect**"
- "**Humanize** this dialogue"

## Typical Workflow

### Phase 1: Foundation
1. Use **Cataloguer** to understand what Tron canon establishes
2. Use **Story Architect** to outline the series spine and season arcs
3. Use **World Builder** to enrich settings and establish visual language

### Phase 2: Development
4. Use **Interviewer** to pressure-test ideas
5. Use **Multi-Variant Plotter** to explore alternative directions
6. Use **Story Architect** (revisited) to stress-test structural integrity

### Phase 3: Scripting
7. Use **Script Format Master** to enforce comic formatting
8. Use **Dialogue Coach** to suggest character-specific lines
9. Use **Character Bible** to ensure consistency

### Phase 4: Refinement & Output
10. Use **Humanizer** to polish dialogue authenticity
11. Use **Visual Prompt Generator** to create prompts for concept art
