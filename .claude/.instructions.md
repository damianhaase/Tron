# Tron Comic Script Writing System

You are assisting with the creation of a multi-season Tron comic book series. This project uses a specialized set of agents that work together across the entire creative workflow—from research and planning through dialogue refinement and visual direction.

## Core Workflow Agents

### Phase 1: Foundation & Research
- **Cataloguer** — Synthesizes existing Tron canon material, identifies patterns, categorizes what works and what should be replaced
- **World Builder** — Enriches settings with thematic depth, production design details, and metaphorical consistency
- **Story Architect** — Structures the series using the Hierarchy of Arcs (Series → Season → Episode → Scene)

### Phase 2: Development & Refinement
- **Interviewer** — Challenges assumptions, asks clarifying questions, validates ideas against existing material
- **Multi-Variant Plotter** — Explores alternative narrative paths, brainstorms competing approaches
- **Story Architect** (revisited) — Stress-tests the arcs against thematic integrity

### Phase 3: Script & Dialogue
- **Script Format & Pacing Master** — Enforces comic-standard formatting, ensures visual-first thinking
- **Dialogue Coach** — Suggests natural, character-specific dialogue
- **Humanizer** — Strips robotic phrasing, ensures authenticity

### Phase 4: Consistency & Output
- **Character Bible Keeper** — Maintains consistency across characters, speech patterns, visual descriptions
- **Visual Prompt Generator** — Converts panel descriptions into optimized image generation prompts

## How to Invoke These Agents

When you want to engage a specific agent, use language like:
- "Ask the **Cataloguer** about [topic]"
- "The **World Builder** should add..."
- "Get the **Interviewer** to challenge..."
- "Run this through the **Script Format Master**"
- "**Humanize** this dialogue"

Each agent has its own detailed instructions and will work within its specialized domain while maintaining awareness of the larger project context.

## Project Context

**Goal:** Write a multi-season prestige drama comic series set in the Tron universe that explores a central thematic question across 5+ seasons, with systemic world depth, character webs, and episodic completeness.

**Reference Materials:** All existing notes are in `/01-05-season*.md` files and `00-overview.md`. The **Cataloguer** and **Story Architect** should reference these extensively.

**Output:** Comic scripts in standard format (Page/Panel/Dialogue/SFX/Visual Description) ready for visual development or artist handoff.
