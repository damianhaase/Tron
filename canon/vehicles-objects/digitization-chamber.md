# Digitization Chamber / Scanning Terminal

## Appearance
- High-tech apparatus with precision beam technology
- Located in [ENCOM Headquarters](../settings/encom-headquarters.md) research lab
- Glowing control panels and displays
- Scanning beam creates visual portal effect
- Physically imposing; occupies significant space

## Function
- **Digitization:** Scans human body and consciousness; converts to digital form
- **Deresolution:** Reverses process; returns digital consciousness to physical form
- **Calibration:** Requires precise tuning to function safely
- **Power source:** Connected to ENCOM's main computing systems

## Mechanics
- Scanning process is not instantaneous; takes time
- Beam must have clear target
- Reverse digitization (return to physical) requires proper calibration
- If scanning node is destroyed, cannot digitize/deresolution anymore

## Key Moments in Tron (1982)
- **Flynn's digitization:** MCP initiates remotely; Flynn pulled into Grid from arcade
- **Lora's digitization:** MCP pulls Lora into Grid as control measure
- **Return of Flynn, Lora, Yori:** Appear in scanning chamber upon their return
- **Destruction of scanning node:** [Kevin Flynn](../characters/kevin-flynn.md) destroys this critical component during final confrontation

## Critical Vulnerability
- **Single point of failure:** Destruction of scanning node removes MCP's ability to digitize humans
- **Connection to real world:** The scanner is the MCP's only bridge to human domain
- **Tactical importance:** Destroying this enables human-digital separation

## Thematic Significance
- **Technology as boundary:** Scanner is literal and metaphorical boundary between worlds
- **Danger of bridges:** The technology that enables connection also enables vulnerability
- **Real-world ground:** Physical technology grounds digital threat in reality
- **Mutual dependence:** MCP depends on scanner; humans depend on it for return

## Canon Notes
- Proves digitization is possible but imperfect
- Return via scanner is viable but not guaranteed
- The technology works; the MCP's use of it is the threat
- Destruction of scanning node is as important as destruction of MCP core
